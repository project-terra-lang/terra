# Security Policy

This repository is archived and has no active security maintenance process.

If you use Terra or any part of it, you are responsible for reviewing,
hardening, and maintaining your copy. The code is a research compiler and
language experiment, not a production security boundary.

Please do not rely on the original repository for vulnerability triage,
embargoes, patches, or coordinated disclosure. Forks and downstream products
should establish their own security policy.
