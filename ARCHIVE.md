# Project Archive

Terra is complete as a personal research project.

This repository is intentionally being archived as a public artifact. The
milestones that guided the work are complete, the implementation is tested, and
the project is left in a state that interested people can study, fork, reshape,
or use as a starting point for something else.

This project was entirely vibecoded. It was built as an exploratory language
and compiler experiment, guided by curiosity and iteration rather than by a
formal product roadmap.

If you are interested in Terra, please feel free to take the project in whatever
direction you think is better. You may preserve it, rewrite it, turn it into a
different language, use pieces of it in another project, publish your own fork,
or sell it as part of your own product. No credit is requested or required.

The repository is provided as-is. There is no expectation of ongoing
maintenance from the original author.

Thank you for taking a look. Have a nice day.
