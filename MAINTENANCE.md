# Maintenance Status

Terra is no longer actively maintained by the original author.

The project is considered complete as a personal research artifact. All planned
milestones in `TODO.md` were completed before archival. Future work is welcome
in forks, but the original repository should be treated as a stable snapshot
rather than an active upstream.

## What Is In Scope For This Archive

- Preserve the completed code, examples, tests, and documentation.
- Make the license and reuse permissions clear.
- Leave enough context for future forks to continue the work independently.

## What Is Out Of Scope

- New feature requests.
- Bug-fix commitments.
- Release management.
- Package publishing.
- Official editor or language-server support.
- Production support.
